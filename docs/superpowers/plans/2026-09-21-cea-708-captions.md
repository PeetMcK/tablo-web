# CEA-708 Captions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Decode CEA-708 alongside EIA-608 on the MPEG-2 paths, render captions where the broadcaster placed them, and fall back to the working 608 path whenever 708 carries nothing.

**Architecture:** `extract.ts` returns DTVCC pairs as well as 608 pairs. A vendored Shaka 708 decoder turns them into cues carrying a window region and styling. The session runs both decoders and latches onto 708 the first time it produces a cue. `CaptionOverlay` places a cue from its region against the title-safe area, or bottom-centres it when there is none.

**Tech Stack:** TypeScript, React, Vitest, Shaka Player's `lib/cea` (Apache-2.0) vendored as source.

**Spec:** `docs/superpowers/specs/2026-09-21-cea-708-captions-design.md`

## Global Constraints

- **`erasableSyntaxOnly: true`** — no `enum`, no parameter properties, no namespaces, including in vendored code. Shaka uses `goog.define` and Closure annotations; both must go.
- **`verbatimModuleSyntax: true`** — type-only imports written `import type`.
- **`noUnusedLocals` / `noUnusedParameters`** are on.
- **608 must not regress.** It is the fallback and the floor. Every existing caption test stays green, unchanged.
- Vendored files record their provenance and pinned version in the header, as `cea608.ts` does.
- Both decoders are fed through the **same PTS reorder buffer**. DTVCC is a sequenced packet protocol — out-of-order delivery corrupts reassembly, not just letter order.
- Work happens in a worktree. Frontend commands run from `frontend/`.
- Baseline: `npm test` → 61 files, 886 tests, 0 failures.

- [ ] **Step 1: Write the failing test against the real fixture**

```ts
it("decodes service 1 out of the committed fixture, with placement", () => {
  // Same reorder discipline the 608 path needs: feed in PTS order.
  const track = createCea708Track();
  for (const { seconds, pairs } of dtvccFromFixture()) track.add(seconds, pairs);
  const cues = track.flush();

  expect(cues.map((c) => c.text).join(" ").replace(/\s+/g, " "))
    .toContain("Elliot had shown them how to find light in the darkness.");
  // Two windows, at the two horizontal anchors the spec measured.
  const anchors = new Set(cues.map((c) => c.region?.xPercent));
  expect(anchors.size).toBeGreaterThan(1);
});
```

- [ ] **Step 3: Implement `Cea708Track`**
